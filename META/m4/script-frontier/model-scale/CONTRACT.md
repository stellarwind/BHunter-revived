## Two-owner contract

The existing `BHModel` offsets and BSP record types match the raw layouts. Scale first tests model->frame: any nonzero value is a complete no-op, including cache invalidation/radius. With frame zero, it scales every vertex x/y/z with per-component binary32 stores. For each node it divides normal x/y/z by sx/sy/sz with binary32 stores, calls admitted real `bh_vec3_normalize` (`004011f0`), reconstructs the plane, scales both AABB endpoints and swaps each endpoint pair for a reflected axis. It reflects face winding only if the evaluated determinant `(sz*sy)*sx` has negative sign under the original comparison. Counts are signed loop tests in the raw owner.

**Plane precision/order:** before normalizing, old normal components multiplied by negative old plane are each spilled to binary32 (`00470ec0/ec7/ecf` addresses: actual stores ec0,ec7,ecf). Define these as px,py,pz. After normalization the x87 computes X=(double(px)*sx)*new_nx, Z=(double(pz)*sz)*new_nz, Y=(double(py)*sy)*new_ny, and stores **-((Z+X)+Y)** as binary32. This differs from the misleading decompiler association. Normal-component division stores and these three point spills must not disappear into a fused mathematical expression. Native x87 precision is caller-owned; use the established PC53 finite contract and actual rounding owner where explicit binary32 stores are needed.

AABB endpoint products store binary32. The determinant is x87 sequential multiplication without an intervening binary32 store. After cache invalidation the owner unconditionally reads node0 bounds, takes the greater magnitudes on each axis, and stores sqrt((X*X+Y*Y)+Z*Z) as binary32 radius. Valid loaded models must have a root node. Finite, nonzero scale vectors provide the meaningful geometry contract; source guard policy for zero/nonfinite/overflow must be explicit rather than assumed from decompile. Raw negative tests use x87 C0 (`TEST AH,1`), which also treats unordered as the branch-taken case; NaN handling cannot be replaced silently by C `<0` if that input is accepted. Maximum comparisons use `TEST AH,41`, retaining the first magnitude on unordered.

`00470d50` receives an edge-owner view (original caller passes model+8, so helper +44 resolves model->edges), start edge and edge count. Count0 returns start, count1 returns the next link, larger counts recursively process next/count-2, swap the first/last **vertex,u,v payload only**, preserve every edge->next link, and return the edge following the far endpoint. This reverses geometric/UV ordering while keeping edge slot topology and face.first_edge unchanged. It is not a next-link reversal. The whole scale owner counts each face's negative-terminated edge chain before invoking it. Validated acyclic model topology is required; recursive negative/unbounded counts are not valid source input.
