Source safely bounds that to supported prefix digits `1..9` and letters `A..C`; this is an explicit adapter limit, not an exact undefined-memory emulation. `display_phase` names the `004dfb4c` deferred-repeat flag adequately.

The first review only covered the plain-text producer record. Subsequent consumer inspection found its callback identity `00477e80` differs from positioned text callback `00477ea0`: `00477e80` calls atlas text `00470900` at the current cursor and returns the next command; `00477ea0` first calls cursor setter `004708d0` using the command's X/Y. The source now uses `BH_TEXT_COMMAND_PLAIN` and a dedicated `bh_message_text_drain` path, preserving the existing positioned queue variant. The native fixture checks successive `H`, `I`, and newline commands so cursor accumulation and line motion expose a mistaken reset; its linked result records 53 checks and zero failures. This is a source selector fix, not a change to the producer's other bytes. The generic text drain intentionally accepts only positioned TEXT/CLEAR commands; any queue containing panel PLAIN records must use `bh_message_text_drain`, which accepts all three kinds.
