# Blender static export data review (2026-10-25)

Reviewed `tools/export_blender_level.py`, `tools/blender_level_scene.py`, the immutable asset index, source BSP/PCX/world transforms, and the generated Desktop `level-data.json` and validation. The export has 454 registered BSP models and all 5,815 `TEST.LEV` placements. Its 10,367 exported polygons equal the raw face count across those models, so no BSP faces were dropped. Each Blender mesh is shared by placements of the same model; source face IDs, material indices, edge UV pairs, placement index/flags/position and script sidecars are retained. Source `bh_world_geometry_build` rotates around game Y by `(flags&3)*pi/2`; mapping game `(x,y,z)` to Blender `(x,z,-y)` converts the game's negative-Y up direction to Blender positive Z, and requires the exported negative Blender yaw. BSP edge `(u,v)` becomes Blender `(u,1-v)` to compensate top-left PCX rows. `bh_texture_load` canonicalizes GIF/TGA/BMP/JPG names to PCX, and original startup switches to palette policy `(1,0xff00ff)` before later resources; the PNG key transform reflects that policy.

The initial `.blend` had a metadata loss: Blender material identity was only texture filename (or helper name), while source BSP materials also carry distinct 9-byte attributes. Across the exported models, 70 such keys have more than one attribute tuple (up to 14). `level-data.json` kept every tuple, but the shared Blender material custom property `BHunter_material_bytes` preserved only the first. This also affects material color/light inspection.

The exporter was updated to distinguish materials by `(texture, attributes)` and rerun. Current `blender-validation.json` reports 502 Blender materials, each carrying its own source bytes; the prior 382-material build is historical and should not be cited as final.

The initial world/prop collection split also counted `PORTAL.GIF` material slots that no face used. `bh_world_geometry.c::classify` sets portal count from actual portal faces. The exporter now derives `shell` from referenced face material indices. The corrected Desktop validation has 1,453 world objects and 4,342 prop objects, moving 34 placements from the mislabeled world collection while leaving all meshes and transforms intact.

The 20 placements without visible textured meshes are 18 `SP_ROOF.BSP` and 2 `SCRAPSKY.BSP`, retained as hidden helper objects. `SP_ROOF` references `roof.gif`, canonicalized to `ROOF.PCX`, which is absent from the embedded archive; source `bh_model_draw_face` skips a null image. Their hidden state is consistent with source rendering from these assets. Exposing a placeholder is optional inspection UX, not a fidelity correction.
