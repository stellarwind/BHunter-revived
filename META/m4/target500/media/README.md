Four complete distinct original owners449c20/449cc0/449d40/449df0 compile in src/bh_media_control.c against existing real BHCdAudio/BHCdNotify/BHCdClose storage. Source context adds call/argument/HRESULT diagnostics without creating devices or duplicating playback state. TMSF packing retains overlapping bitwise OR of the16-bit middle field and8-bit frame field. STOP clears repeat before calling native STOP and retains device ownership.

Volume owners skip sentinel-1 endpoints; otherwise original unordered/lower clamp maps to0, upper clamp to1, and retained extended product65535 truncates before stereo duplication.
