# Independent source review

Reviewed src/bh_render_state.c/h and tests/render_state.c against complete retained0045b410/0045b490/0045b500 instruction listings, the original five-entry jump table0045b7f8, actual pinned DX7 SDK d3dtypes.h, and real texture queue/residency implementations. No actionable behavior defect found for supported inputs.

SDK enum verification: ZWRITEENABLE14, ZFUNC23, ALPHABLENDENABLE27, SRCBLEND19, DESTBLEND20. D3DCMP_GREATEREQUAL=7 and ALWAYS=8; source correctly uses GREATEREQUAL for depth0/1 and ALWAYS for2. ZERO=1, ONE=2, INVSRCCOLOR=4, SRCALPHA=5, INVSRCALPHA=6. No LESS assumption remains.

Original jump-table targets are0045b56c/0045b61b/0045b6c2/0045b762/0045b7d7, establishing modes0..4 respectively. Source mappings exactly match depth/blend/source/destination tuples(0,0,2,1),(1,1,2,4),(1,1,1,4),(1,1,2,2),(1,1,5,6). Unknown modes still publish the raw mode after native barrier, without depth/blend cache changes. Unknown depth publishes only depth cache. Blend compares all three raw words and writes enable/source/destination in original order.

Native mode path increments the same BHTextureContext.frame consumed by bh_texture_resident, before traversing image.next and flushing each queue. EndScene then BeginScene precede mode cache publication and depth/blend updates. Unsigned increment preserves32-bit wrapping. Same-mode calls still barrier. Software path suppresses epoch, queue and native calls while retaining original cache/mode behavior. Cycle preflight and invalid binding rejection are documented source guards, not original validinput differences. Context init is correctly labeled an adapter applying actual native defaults rather than assuming cache agreement.

HRESULT behavior: originals ignore results and continue. Source caches publish before native setters and all later setters/barrier calls still execute after an earlier failure; returnstatus/counters are source diagnostics and do not rollback. Queue flush failure sets overall returnfailure but still permits later images/EndScene/BeginScene/state changes. Diagnostics from queue ownership live in BHTextureContext, while direct render-state nativecalls/failures live in BHRenderState; the counters are not a complete count of all native calls made by nested residency/flush helpers. last_hresult tracks the last direct nativecall and may be success after earlier failure; failures/returnstatus retain the failure. No code change required.

Existing native tests exercise all modes, SDK numeric results, cache suppression, unknown values, shared epoch including wrap, actual pending fan flush and software retained queue, and real pixels before mode changes. Failurecontinuation semantics were checked statically here; the retained57-check green run does not constitute native HRESULT fault-injection coverage. This review performed no game/originalcode execution and did not modify implementation/tests.
